# unitree-g1-agentic source backup

This directory preserves the pre-voice-agent source composition used as the
reference for `unitree-g1-voice-agentic`.  It is intentionally a source-level
backup: the original runnable blueprint remains unchanged at
`dimos/robot/unitree/g1/blueprints/agentic/`.

The backup contains the hardware and simulation entry points plus their shared
agent/skill bundle.  It does not snapshot generated model data, virtual
environments, or runtime state.
